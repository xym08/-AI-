# 后续AI视觉与展板规则

本文件是下一轮制作约定，本轮不执行生图。图像表达学生组概念方案，不标成实物照片、试烧样品、CAD校核或性能试验。

## 每题先建立一致的输入

| 输入 | 写清什么 |
|---|---|
| 方案版本 | 作品名、日期、采用哪份结构说明；名称尚未检索时标暂定 |
| 用户与场景 | 谁赠、谁用、在哪一步遇到问题；调研与假设分开 |
| 文化依据 | 来源事实、设计推导、视觉隐喻分别写 |
| 部件 | 数量、形状、职责、装配与取出位置 |
| 尺寸 | 外包络、内净尺寸、容量目标和未知数；不得从外体积冒充容量 |
| 材料 | 外饰、受力、接触、密封或光学作用，不能用一个材料名概括全部 |
| 视图 | 主视觉、结构/状态、使用场景中哪些对象必须完全一致 |

## 五个方向的首轮画面边界

| 方向 | 必须保留 | 直接退回的画面问题 |
|---|---|---|
| 瓷候 | 低矮白瓷、实心可拆盖、四组侧缝、深色隐藏控香件 | 无火器具冒烟；从实心盖排香；0°与90°同周期却标闭到全开 |
| 一席之间 | 新版轻量奉茶席、固定器物、确定的面板和铰接数 | 三片长度冒充四片；55高盒装入明显更高器物；纸板直接蓄水 |
| 白瓷光笺 | 同一瓷壳、同一固定信息、真实底座位置 | 瓷器变玻璃；投影或无限精细文字；光穿过电池；不同状态换外形 |
| 合礼 | 确定的字形底图、真实件数、中心支撑及四项用途 | 中心实体浮空；拼字多出零件；手机无背靠；杯底压在细缝上 |
| 竹·行 | 固定模块数、竹外套/内衬分工、独立茶渣封口 | 食品与茶渣混放；接口凭空增减；大于外包络的容量；不见壁厚 |

## 通用生成提示词骨架

作品与用途：〔作品名、选定使用场景、学生组概念效果图〕。

设计输入：〔已确定的结构版本和参考底图〕。参考图只提供明确指定的外形/结构关系，不照搬其他品牌造型。

主体与部件：〔准确数量、形状和功能〕。保留〔不可变清单〕。

材料与比例：〔材料职责、表面、比例与待验证尺寸〕。

画面：〔主视觉或结构/状态对比〕。风格简洁，光线真实，尺寸文字留给后期排版。

约束：不增加未定义零件，不改变同一产品各视图的几何，不把气味画为烟，不虚构实验仪器数据或通过认证标识。〔追加该题退回条件〕。

生成后按“形状是否一致→功能关系是否清楚→材料是否真实→文字与尺寸是否另排→是否误导为验证结果”检查。一次只修一个明确问题，记录修改原因。

## 展板内容顺序

1. 名称、明确场景和一句话概念。
2. 一个可核查的文化来源与其转译关系。
3. 产品主视觉及部件关系。
4. 使用前、使用中、使用后的连续过程。
5. 关键结构与材料职责；尺寸状态清楚。
6. 与具体先例的区别、当前限制与AI辅助披露。

用户尚未提供赛区正式尺寸与页数要求时，版面只称工作母版。应保存可调整源文件，不把A3、两页或300dpi写成官方规范。

## 文件与同步

每题使用独立目录和版本号，当前七题编号保持不变。完整生成提示词、参考来源及评审记录一并保存；本地默认D:\skill下独立项目文件夹，GitHub按项目目录同步。

保存本地不等于已同步。每次远端更新须记录提交、核对新文件与README链接、确认旧文件保留后，才报告“同步完成”。未提交赛事也不得称“参赛流程全部完成”。
