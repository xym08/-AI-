## 筛选结果

| 编号 / 核心字 | 作品 | 文化转译 | 本轮位置 | 下一步先解决什么 |
|---|---|---|---|---|
| 01 品 | 茶与香 → **瓷候** | 茶事节奏 → 香器使用行为 | 保留为已深化基准 | 沿用已修订方案；不把旧角度和盒高重新写成定稿 |
| 02 席 | **一席之间** | 待客礼序 → 双人使用空间 | 优先深化 | 区分新版轻量奉茶席与历史完整冲泡湿区版；确认折叠与装箱 |
| 03 光 | **白瓷光笺** | 瓷壁厚薄 → 固定信息显现 | 优先深化 | 明确赠礼情境、显现内容与光源/电池布局；不把薄瓷透光当首创 |
| 04 行 | **竹·行** | 竹节 → 分段收纳与接口识别 | 有条件进入第五个方向 | 先删食物/废茶通用，分离洁污；竹环不承担主密封 |
| 05 合 | **合礼** | 字义 → 拆用与归位组合 | 优先深化 | 用二维轮廓解决“合”字负形和中心实体支撑，明确真实件数 |
| 06 航 | 海丝·一帆 | 海贸旅程 → 展开、定位与抵达 | 海丝专项备选 | 证明立帆器架的实际用途及闭合收纳位置 |
| 07 同 | 同潮 | 来往与相聚 → 双人共享关系 | 交流主题备选 | 保证每只杯独立稳定；拼圆不依赖弧面承重底或两杯相互扶持 |

“4＋1”包含已有的《瓷候》；新增优先深化3题，另保留《竹·行》1题有条件推进。两项备选不删除，也不马上批量生成效果图。若确定专项赛区主题，再重排优先次序。

## 后续工作顺序

**先核对赛题 → 明确一个场景 → 固定部件与尺寸假设 → 完成二维结构自洽检查 → AI效果图 → 逐图复核 → 展板与说明 → 本地保存及GitHub同步。**

新方向建议先从《合礼》和《白瓷光笺》开始，因为它们能检验这套方法是否适用于茶香器之外的品类；《一席之间》先解决版本与空间预算。《竹·行》完成简化条件后再进入同一队列。每次集中深化一题，避免七题同时改形。

本库中的结构修订属于建议路线，不是已经取得的测试结果。AI图只表达设计意图，学生组效果图要求与AI辅助规则仍需按具体赛区最新通知确认。
