# 茶与香｜AI视觉开发

## 当前核心产品

旋转控香器 + 展开式香席包装

## 当前视觉验证重点

1. 闭 / 微启 / 舒展三种控香状态
2. 白瓷外壳与旋转控香环关系
3. 无火香芯结构
4. 底部进气与上部出香路径
5. 白瓷器物感
6. 降低普通香薰机、家电感
7. 展开式香席包装
8. 包装与产品的使用关系

## 当前视觉原则

- 温润象牙白德化白瓷
- 半哑光釉面
- 柔和现代几何造型
- 无火香芯
- 三档机械控香
- 不使用复杂电子系统
- 不使用茶叶纹样、祥云、龙凤、福建地图、红金装饰
