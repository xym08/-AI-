## 本轮设计决定

一体白瓷罩、连续承托底座、固定山水图形、暖光扩散组件。关灯仍可见微弱肌理，点亮加强显影；不宣称动态换图或多级信息显现。电子件仅为布局概念，壁厚、烧成、温升、续航尚未测试。
