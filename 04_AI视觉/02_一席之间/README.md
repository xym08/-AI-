## 本轮设计决定

四折席面、两只低杯、一只分享碟、两只可清洗接水垫；使用外部已泡好的茶。本轮采用可取出的四折席面加独立礼盒与保护内托，替代“全部盒壁直接展开成席”的未解决构造。闭合尺寸、折叠堆叠和内托容积仍待尺寸设计。历史完整冲泡/残水仓版本不混用。
